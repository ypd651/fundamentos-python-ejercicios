# Fundamentos de Python — Ejercicios de Clase

Colección de ejercicios prácticos en Python enfocados en reforzar los fundamentos de programación y la lógica para la resolución de problemas sencillos.

> Proyecto académico de nivel introductorio. Código claro y comentado con fines de aprendizaje.

## Contenido

Ejercicios organizados por temas:

- Variables y tipos de datos
- Operadores aritméticos y lógicos
- Entrada y salida de datos (`input()` / `print()`)
- Condicionales (`if`, `elif`, `else`)
- Ciclos (`for`, `while`)
- Funciones
- Listas y diccionarios básicos
- Manejo básico de errores
